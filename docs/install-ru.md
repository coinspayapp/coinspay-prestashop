# CoinsPay для PrestaShop — установка

Модуль принимает оплату криптовалютой через CoinsPay: покупатель выбирает монету и сеть на
странице оплаты CoinsPay, а заказ сам получает статус, который вы выбрали для каждого события
счёта. Деньги сразу уходят на ваши кошельки.

Один архив `coinspay.zip` подходит для PrestaShop от 1.6.1 до 9.x на PHP от 5.6 до 8.5. Нужен
аккаунт CoinsPay с магазином.

## Установка

1. Загрузите `coinspay.zip` в админке:
   - PrestaShop 1.7–9: «Модули → Менеджер модулей» → «Загрузить модуль»;
   - PrestaShop 1.6: «Модули и сервисы» → «Добавить новый модуль».
2. Нажмите «Настроить» у модуля «CoinsPay: оплата криптовалютой».

PrestaShop предупредит, что модуль «не проверен PrestaShop»: так он пишет о любом модуле не из
каталога Addons. Подтвердите установку.

Модуль добавляет два статуса заказа: «Ожидает оплаты криптовалютой» и «CoinsPay: проверьте
платёж».

## Подключение

1. В кабинете CoinsPay откройте магазин.
2. В разделе «Ключи API» выпустите ключ с доступом **«Только счета»** и вставьте его в поле
   «Ключ API». Модулю больше не нужно, а вывести деньги таким ключом нельзя, даже если его
   прочитает кто-то из сотрудников с доступом к админке.
3. Поле «Адрес API» оставьте пустым: тогда модуль использует `https://coinspay.app/api/v1`.
4. В разделе «Вебхук» укажите адрес, который показывает модуль, сохраните и скопируйте секрет
   `whsec_…` в поле «Секрет вебхука».
5. Сохраните, нажмите «Проверить подключение», затем в кабинете — «Отправить тестовое
   событие»: в модуле появится время, когда событие дошло.

Валюты, страны и группы покупателей, которым виден способ оплаты, задаются в разделе
«Оплата → Настройки», как у любого платёжного модуля.

## Статусы заказа

На вкладке «Статусы заказа» каждому событию счёта сопоставлен статус. По умолчанию:

| Событие счёта | Статус заказа |
|---|---|
| Заказ оформлен, ждём оплату | Ожидает оплаты криптовалютой |
| Платёж в пути, оплачен частично | не меняется, только сообщение |
| Оплачен (в срок, после срока, с переплатой, отмечен вручную) | Платёж принят |
| Истёк без оплаты, счёт отменён | Отменён: PrestaShop вернёт товар на склад |
| Сумма не совпадает, оплачен отменённый заказ, тестовая оплата не от тестового покупателя, истёк или отменён с частичной оплатой | CoinsPay: проверьте платёж |

В списках есть и ваши собственные статусы. При каждом событии к заказу добавляется личное
сообщение с суммами, монетами и хешами транзакций; покупатель его не видит.

«Статусы отмены заказа» — статусы, при переводе в которые модуль отменяет открытый счёт. По
умолчанию выбран «Отменён».

## Тестовый режим

С ключом `cpk_test_` счета оплачиваются кнопкой на странице оплаты, монеты не переводятся. По
умолчанию способ оплаты тогда виден только тестовому покупателю: откройте магазин по кнопке
«Открыть магазин как тестовый покупатель» в настройках. Ссылка действует сутки в том браузере,
где вы её открыли. Тестовая оплата закрывает только заказы тестового покупателя.

## Если вебхуки не доходят

Модуль сам спрашивает CoinsPay об открытых счетах: со страниц магазина не чаще раза в 5 минут
и при открытии «Адреса для cron» из настроек. Для магазина с небольшим числом посетителей
добавьте этот адрес в cron хостинга раз в 5 минут.

Адрес вебхука должен оставаться адресом самого магазина, как его показывают настройки:
PrestaShop перенаправляет другие имена хоста на него, а вебхуки перенаправлениям не следуют. В
режиме обслуживания PrestaShop не принимает вебхуки — опрос наверстает после.

## Несколько магазинов (multistore)

Настройки хранятся отдельно для каждого магазина. Выберите один магазин вверху админки, затем
откройте настройки модуля.

Магазины могут работать с одним магазином CoinsPay: тогда его вебхук приходит одному из них, а
тот передаёт события о счетах других магазинов дальше. Или заведите каждому магазину свой магазин
CoinsPay со своими ключом и вебхуком. Магазин, созданный позже с «Импортом данных» из другого,
получает настройки модуля этого магазина.

## Полезно знать

- Заказ оформляется до оплаты, как при банковском переводе: PrestaShop сразу отправляет письмо
  о заказе и резервирует товар.
- Покупатель, закрывший страницу оплаты, может заплатить позже: в его кабинете на странице
  заказа есть кнопка «Перейти к оплате», пока счёт открыт.
- Счёт выставляется в валюте заказа, если CoinsPay её принимает, иначе — в основной валюте
  магазина.
- Журнал отладки пишется в «Расширенные параметры → Журналы». Ошибки записываются всегда,
  ключи и секреты — никогда.
